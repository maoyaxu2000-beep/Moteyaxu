# 自动测试

改完代码后跑一遍，几十秒就能确认主要功能没被改坏。

```bash
cd tests && npm install      # 只需第一次（装 Playwright 和浏览器）
npm test                     # = node smoke.js && node gate.js
```

| 脚本 | 测什么 |
|---|---|
| `smoke.js` | 用模拟学习内容（`mock-data.js`）打开 `harness.html`，走一遍：间隔复习、收藏、执勤速查、给旅客看、备份与恢复（含截断/乱码/损坏数据）、跟读录音、打卡海报、深浅色、关于与诊断，并检查全程没有脚本错误 |
| `gate.js` | 邀请码进入流程：错码、正确码、之后免输入、断网进入、管理员作废、更换主密钥、个人码过期、水印编号 |

- `gate.js` 用 `fixture.js` 现场生成**测试用**的主密钥和邀请码（加密方式与 `admin/build_secure.py` 一致），完全不涉及真实密钥。
- 两个脚本都会自己起本地静态服务器，不需要手动启动任何东西。
- 想看某个页面的截图：给 `smoke.js` 加 `SHOT_DIR=/some/dir` 环境变量，会把海报等截图存下来。
